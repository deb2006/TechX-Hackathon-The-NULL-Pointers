# Proof of Life · Liveness Detection

A real-time liveness detection system that verifies human presence through:
- 👁️ Blink detection (2 blinks required)
- 😊 Smile detection
- 👤 Face presence verification

## Setup

1. Update `COLAB_URL` in `script.js` with your Colab ngrok URL
2. Open `index.html` in a browser
3. Allow camera access
4. Complete the challenges to get your Proof-of-Life token

## Architecture
- Frontend: Vanilla JS, HTML5, CSS3
- Backend: FastAPI (Replit)
- AI: MediaPipe (Google Colab)

## Features
- Dark theme UI
- Real-time feedback
- Progress tracking
- 5-minute JWT tokens
